ExpertenmodusBytes, Zeichencodes und ASCII

Was lernst du hier? Eine Bitfolge ist zunächst nur ein Muster aus 0 und 1. Damit daraus ein Buchstabe wird, braucht man eine gemeinsame Vereinbarung: einen Zeichencode.

Informatik dahinter: Im klassischen ASCII-Code hat jeder Buchstabe eine Zahl. Zum Beispiel ist R = 82. Diese 82 kann wiederum als Byte 01010010 gespeichert werden. So verbindet der Computer drei Ebenen: Bits → Zahl → Bedeutung.

Heute: Moderne Texte verwenden meist Unicode bzw. UTF-8. ASCII ist aber weiterhin wichtig, weil die ersten 128 Unicode-Zeichen mit ASCII übereinstimmen und das Prinzip sehr anschaulich zeigt, wie Daten codiert werden.
